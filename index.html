操作ガイド

パッドの再生

  • パッドのクリック、または割り当てたショートカットキーで再生する。動作はサウンドごとの「起動」設定（トグル / ホールド / リトリガー / レイヤー / ポーズ / ミュートなど）に従う。

Option / Alt + クリック（一時停止）

  • Option/Alt を押しながら再生中のパッドをクリックすると、そのサウンドを一時停止する。もう一度押すと同じ位置から再開する。
  • 起動モードは問わず有効。レイヤー（重ね再生）のボイスも位置を保ったまま、まとめて一時停止・再開する。
  • ホールド系モード（押している間だけ再生）も、Option/Alt を押したまま離すと一時停止になる。
  • キーを押している間、再生中パッドのアイコンが一時停止表示に変わる。

全停止・全一時停止

  • Esc または「全停止」ボタン: 再生中の全サウンドを停止する（位置はリセット）。
  • Option/Alt + Esc、または Option/Alt を押しながら「全停止」ボタン: 全サウンドを一時停止する。もう一度で全再開する。

※ Mac は Option キー、Windows / Linux は Alt キー。
