ポン出し用Webサウンドボードです。音声ファイルをブラウザに追加し、シーン単位で管理・再生できます。

## 主な機能

- 音声ファイルの追加と複数ファイル選択
- 可変長ドラムロール（起こり→ループ→終わり→締めの4パート構成。キーを押している間ループし、離すと終わり→締めまで自動で再生）
- シーンの追加、選択、名前変更、削除
- シーンデータのインポートとエクスポート
- サウンドごとの再生、停止、ループ、音量、シーク、フェード設定
- 前後の無音を検出して除外する非破壊トリム、開始/終了秒を指定する再生区間設定（ループは区間内でつながる）
- EQ、Delay、Compressor などのエフェクト設定
- マスター音量、レベルメーター、波形表示
- システム既定または指定デバイスへの音声出力切り替え
- リミッター後のマスター出力録音、シーン保存、音声ファイルのダウンロード
- クリック優先モードとドラッグ編集モードの切り替え
- ショートカット割り当てを可視化・操作できるキーボードビュー
- ダークモード、パッドサイズ変更
- 遠隔操作（WebSocket中継 via ws.nopo.dev）。音を出す端末を「ホスト」、スマホ/タブレットなどを「コントローラー」にして、メインと同じ画面でパッド再生・エフェクト調整・シーン管理などを遠隔から操作
- PWAとしての利用とService Workerによるキャッシュ

## 技術構成

- Vite
- Bun
- Tone.js
- Web Audio API
- IndexedDB
- localStorage
- Service Worker / Web App Manifest
- WebSocket (ws.nopo.dev / cfws-worker による中継)

## データ保存

アプリのデータはブラウザ内に保存されます。

- シーンと音声ファイル: IndexedDB
- 表示設定や操作設定: localStorage / IndexedDB

IndexedDBのDB名は `ponndashiDB_v2` です。別ブラウザや別端末には自動同期されません。移行やバックアップには、アプリ内のエクスポート機能を使います。
## 遠隔操作

1. 音を出す端末（ホスト）: シーン設定の「リモート操作」で「ホスト」を選ぶとルームIDが生成される
2. 操作する端末（コントローラー）: `/remote/` を開いてルームIDを入力して接続

- **ホスト**: 音を出す端末。コントローラーからのコマンドでパッドを再生し、シーン/パッド設定・マスターエフェクト・再生状態を配信する
- **コントローラー** (`/remote/`): メインアプリと同じ画面を使うリモコン専用ページ。ホストの状態をミラー表示し、パッドの再生・停止、パッド音量/ループ/シーク、サウンド設定（フェード/PAN/速度/起動モード/カラー/パッド別エフェクト）、マスター音量・リミッター・マスターエフェクト（EQ/COMP/DELAY/PAN/DIST/REVERB）、シーン追加/名称変更/色/削除/並べ替え、キーボードビュー、録音開始/停止を遠隔から操作できる。ルームIDの生成はできず、入力のみ
- コントローラーの物理キーボードでも、ホストの現在シーンに割り当てたショートカットを使える。修飾キー、長押し、ドラムロールに対応し、入力欄や設定画面の操作中は再生しない。ウィンドウから離れたりタブを切り替えたりすると長押しを解除する
- ホストの音声データが必要な要素（波形・レベルメーター・LUFSノーマライズ/無音トリム・ロールパート編集・ファイル追加/インポート/エクスポート・出力先選択）はリモコンでは省略される

中継は `wss://ws.nopo.dev/poncue/{ルームID}` (Cloudflare Workers + Durable Objects)。ルームIDは8文字のランダム文字列で、実質的なペアリングキーとして機能します。接続は自動再接続（指数バックオフ）と心跳（5秒間隔、RTT表示）で維持され、再接続後は自動で状態が再同期されます。

## 音声ファイル

音声追加フォームは、主に次の形式を受け付けます。

- MP3
- WAV
- M4A / AAC
- OGG / Opus
- その他ブラウザが扱える `audio/*`

1ファイルあたりの上限は `512MB` です。

## 可変長ドラムロール

ヘッダーの「ロール」ボタンから、起こり・ループ・終わり・締めの4パートを持つドラムロールを追加できます。

- パートの継ぎ目はオーディオクロックで事前スケジュールされ、約5msの微小クロスフェードで途切れなく切り替わります
- ロール再生中はパッドのプログレスバーと波形表示の対象から除外されます（パート切替で表示が忙しく動くため）
- ショートカット割り当ては通常サウンドと同様に設定画面で行え、キーボードビューにも表示されます
- シーンのエクスポート／インポート（ZIP）にパート音声も含まれます

## PWAについて

- `public/manifest.json`：起動URL `/`、アイコンは既存の `favicon.svg`。
- 旧版PWAの起動URL `/assets/index.html` は、`public/_redirects` で `/` へ転送する。この設定ファイルは配信されないためService Workerのキャッシュ対象から除外する。
- 初回オンライン読込後はオフライン再生可能。遠隔操作には通信が必要。インストール可否はブラウザ／OS依存。
- 開発時はService Workerを無効化。PWA確認は `bun run build` → `bun run preview`。Cloudflareの転送確認には `bunx wrangler dev --config wrangler.preview.jsonc` を使う。

## 音声出力先

音声出力先の変更には、`AudioContext.setSinkId()` に対応した Chromium 系ブラウザと HTTPS 接続が必要です。未対応ブラウザではシステム既定の出力を使用します。選択中のデバイスが切断された場合も、システム既定へ自動的に戻ります。
